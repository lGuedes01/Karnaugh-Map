Simplificador de mapas de Karnaugh

Clique numa célula para alternar 0 → 1 → X. O botão direito volta um passo. Com uma célula selecionada, digite 0, 1 ou X e ande com as setas. A expressão mínima é recalculada a cada mudança; passe o mouse sobre um termo para ver o grupo no mapa.

Os mapas ficam guardados só neste navegador. O site não usa cookies nem coleta dados. X é condição irrelevante (don't care): entra num grupo só quando ajuda a simplificar. Código no GitHub
